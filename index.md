## 🧪 What Can This Tool Do?

This toolkit is packed with features that make Raman spectroscopy work much easier. Here's what you can accomplish:

### 🔄 File Conversion (Multiple Formats Supported)

Stop worrying about incompatible file formats! This tool can read and convert the following formats:

- **JASCO .jws files** — Common from JASCO spectrometers
- **CSV files** — Spreadsheet-friendly format
- **SPC files** — A standard spectral format
- **JCAMP-DX files** — Universal spectral exchange format

You can convert any of these to:

- **CSV** — For Excel or other spreadsheet programs
- **Excel** — Directly to .xlsx format
- **PNG** — For images, presentations, or reports

### 🔍 Peak Detection and Fitting

Finding and analyzing peaks is critical in Raman spectroscopy. This tool includes:

- **Automatic peak detection** — The app finds peaks in your spectrum automatically
- **Peak fitting** — Fit Gaussian, Lorentzian, or mixed curves to your data
- **Parameter adjustment** — Adjust peak position, height, and width with easy controls
- **Visual feedback** — See the fitted curve overlayed on your original data instantly

### 🪨 Mineral Band Assignment

Raman spectra often contain characteristic bands that help identify minerals. This feature:

- **Assigns known mineral bands** to peaks in your spectrum
- **Provides reference information** for common minerals
- **Shows which peaks correspond to which mineral features**

### 📚 Reference Library Search

Never be stuck trying to identify an unknown spectrum again! The tool integrates:

- **ROD database** (Raman Open Database) search
- **RRUFF reference library** search
- **Quick lookup** for common minerals and materials

### 🧬 Unknown Spectrum Identification

Have a mystery sample? The identification feature:

- **Compares your spectrum** against thousands of reference spectra
- **Ranks the best matches** with confidence scores
- **Pairs your spectrum** with matching references side-by-side for easy comparison

### 🌐 Bilingual Support (English & 中文)

This application is fully bilingual:

## 📊 Understanding Your Results

When you identify a spectrum, the app provides:

- **Match score** (percentage similarity)
- **Reference spectrum name** and source database
- **Chemical formula** (when available)
- **Mineral name** (for mineral samples)
- **Comparison plot** showing your spectrum and the reference

Peak fitting results include:

- **Peak position** (Raman shift in cm⁻¹)
- **Peak height** and **area**
- **Full width at half maximum (FWHM)**
- **Fit quality indicator** (R² value)

## 🛠️ Tips for Best Results

- **File quality** — Use clean spectra with minimal baseline drift for best identification accuracy
- **Baseline correction** — If available, apply baseline correction before peak fitting
- **Database search** — For mineral identification, make sure your spectrum has a clear range (typically 100–2000 cm⁻¹)
- **Reference check** — Always visually compare your spectrum with the suggested reference
